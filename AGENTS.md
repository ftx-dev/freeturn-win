# FreeTurnX для Windows

Нативный WPF-клиент для Windows 10 1809+ и Windows 11, архитектуры x64 и ARM64.
Репозиторий: `ftx-dev/freeturn-win`. Основная ветка: `main`.

## Устройство

- `src/FreeTurnX`: WPF/.NET 10, интерфейс, трей, WebView2, обновления.
- `src/FreeTurn.Core`: модели, конфиги, маршрутизация и состояние соединения.
- `src/FreeTurn.Core.Tests`: xUnit, включая проверку локализации.
- `helper/cmd/freeturn-core`: Go-мост к ядру free-turn-proxy.
- `helper/cmd/freeturnd`: служба Windows `FreeTurnDaemon` (LocalSystem).
- `third_party`: upstream-подмодули; не удалять платформенные файлы внутри зависимостей.
- `installer/freeturnx.nsi`: NSIS, исходник UTF-8 с BOM.

Движок Amnezia Box создаёт адаптер `FreeTurn` через встроенный подписанный wintun.
WG/AWG отправляет пакеты на локальный UDP-мост `127.0.0.1`; этот сокет нельзя привязывать к физическому интерфейсу.
Сокеты внешнего транспорта ядра, напротив, должны обходить VPN.
IPC службы: `\\.\pipe\freeturnd`, протокол JSON, версия `1`.

## Работа с кодом

- Интерфейс по-русски; ключи локализации — русский текст. Переводы: `Resources/Strings.en.json`.
- Использовать существующие `Ui` и `Motion`; уважать настройку отключения анимаций и системную настройку.
- Не записывать ключи, ссылки звонков и приватные настройки в логи, скриншоты, коммиты или релизы.
- Значения по умолчанию: релей, автоматическая CAPTCHA, продвинутое решение CAPTCHA, общий профиль «РФ сервисы напрямую», иконка X.
- Новые значения по умолчанию не должны перезаписывать сохранённый выбор пользователя.
- `DomainSuffix` охватывает основной домен и его поддомены, но не похожие домены без границы точки.
- UNIX-файлы helper и shell-фикстуры нужны для переносимых тестов; это не macOS-клиент.
- Не менять пользовательское VPN-соединение Hiddify при проверках. Для UI использовать отдельный `FREETURN_DATA_DIR`.

## Сборка и проверки

Нужны Go (версия из `helper/go.mod`), .NET SDK 10, NSIS 3.

```powershell
dotnet test src/FreeTurn.Core.Tests -c Release
Push-Location helper
go test -ldflags=-checklinkname=0 ./...
Pop-Location
./scripts/Build-Windows.ps1
```

`Build-Windows.ps1` собирает Go-компоненты и вызывает `Package-Windows.ps1`, который всегда заново публикует WPF-клиент.
Иконки ICO и PNG уже включены в репозиторий; Swift/AppKit для сборки не нужны.
Ручные сценарии: `docs/acceptance.md`. Не выдавать успешную компиляцию за проверенное VPN-соединение.
