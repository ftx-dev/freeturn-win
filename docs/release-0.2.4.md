# FreeTurnX 0.2.4 — подготовка выпуска

- Исправлен чрезмерный размер редактора правил приложений. Длинный путь больше не раздвигает форму; кнопка «Сохранить» с акцентом Windows закреплена снизу.
- Ограничены размеры окон выбора приложения и переименования. В импорте действия остаются под прокручиваемой формой.
- Единый стиль подтверждений закрытия, обновления, Telegram, удаления и ошибок импорта. При закрытии можно запомнить «Скрыть» или «Выйти», а затем изменить выбор в настройках.
- В экспериментальных настройках доступно увеличение потоков до 96 всего и 48 на аккаунт. Выключение ограничивает превышенные значения до 24. Ограничения действуют также при загрузке, импорте и подключении.
- Подготовлена сборка MSIX x64/ARM64. Упакованный клиент использует Microsoft Store для обновлений, обычный EXE сохраняет обновления GitHub.

Microsoft Store пока не опубликован: требуются identity приложения Partner Center и разрешения на службу LocalSystem. Тестовые MSIX с локальной identity не предназначены для установки пользователями. Автоматическая отправка на сертификацию ещё не подключена.

EXE не имеет доверенной Authenticode-подписи. Наличие MSIX-сборки само по себе этого не меняет.
