# FreeTurnX для Windows — устройство

Нативный клиент WPF/.NET 10 для Windows 10/11. Движок Amnezia Box использует официальный подписанный wintun.

- FreeTurnX.exe: интерфейс, трей, WebView2 и настройки пользователя.
- freeturn-core.exe: Go-мост к ядру, внешние сокеты обходят туннель.
- freeturnd.exe: служба Windows LocalSystem, управляет движком через именованный канал.
- NSIS: установщики x64 и ARM64, установка службы и регистрация ссылок.

Протоколы между процессами (строки JSON) — без изменений: тот же `ProtocolVersion = "1"`.

## Отличия правил маршрутизации

- Правило «приложение»: путь к `.exe` → `process_path`; путь к папке → `process_path_regex` `(?i)^<папка>\\` (все программы внутри).
- Значение должно быть абсолютным путём Windows (`C:\…`).
- Адаптер туннеля называется `FreeTurn`; при выборе физической сети он и другие туннели исключаются.

## Обновления

GitHub Releases `ftx-dev/freeturn-win`: установщик своей архитектуры (`x64` / `arm64`) + `SHA256SUMS.txt`.
Приложение сверяет сумму, запускает установщик тихо (`/S`) с запросом UAC, после установки открывается снова.

## Проверка

- Логика (`FreeTurn.Core`, net10.0) — тесты xUnit на Windows.
- Go-часть — тесты, сборка и `go vet` под Windows.
- Конфиг движка, собранный C#, проверяет настоящий движок (`check`) и санитайзер службы.
- Интерфейс, служба, туннель — только на Windows: чек-лист в `docs/acceptance.md`.

## Ограничения

- Остановка движка службой — принудительная (у службы нет консоли для мягкого сигнала).
- Без подписи Authenticode: SmartScreen предупредит при первом запуске установщика.
- Канал службы открыт всем интерактивным пользователям машины; конфиг проходит санитайзер, пути к файлам запрещены.
