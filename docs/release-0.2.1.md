# FreeTurnX 0.2.1

Установщики не имеют доверенной подписи Authenticode. SignPath Foundation отклонил заявку из-за недостаточной публичной известности проекта.

- Экспериментальный компактный режим 400 × 600, включается галочкой в настройках.
- Скруглённое выделение серверов и профилей, кнопка добавления под списком на общем фоне; красная кнопка сброса настроек.
- Исправлена высота строк формы сервера при длинной ссылке; поле больше не вытесняет подпись.
- Поле ключа обфускации и кнопка генерации помещаются в компактную строку; в узком режиме кнопка располагается под полем.
- Окно импорта ограничено размером экрана: форма прокручивается, кнопки импорта и отмены всегда остаются внизу окна.
- Изменение настроек сохраняет положение прокрутки.
- Убрано дублирование названия в подсказке трея, меню готовится до первого открытия правой кнопкой.
- Кнопка подключения больше не увеличивается при наведении и нажатии; ожидание показывает вращающаяся белая дуга внутри контура. Настройка отключения анимаций учитывается.
- По умолчанию: релей, автоматическая CAPTCHA, профиль «РФ сервисы напрямую», иконка X. Сохранённые настройки не перезаписываются.
- Обновлены скриншоты README, добавлены компактный режим и меню трея. Опубликован сайт проекта через GitHub Pages.
- Сборка Windows больше не требует Swift; добавлена сборка установщиков в GitHub Actions.

Проверки: 92 теста C#; тесты Go и сборка обеих архитектур в CI; визуальная проверка обычного и компактного интерфейса на Windows x64. После распаковки установщиков проверены версия 0.2.1.0 и совпадение хешей четырёх EXE с выходными файлами сборки.

Полное VPN-соединение direct/relay и запуск на ARM64 в этой проверке не подтверждены. Действующее соединение Hiddify не менялось.

SignPath допускает повторную заявку после роста сообщества и независимых подтверждений доверия. Сертификат проекту не выдан.
