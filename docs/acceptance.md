# Приёмка на Windows

Собрано и проверено на macOS: тесты логики (C#, 91), тесты Go, сборка установщиков x64/arm64,
конфиг ядра принимает декодер ядра, конфиг движка (с путями Windows) — санитайзер службы и сам движок.
Запустить на Windows здесь было негде — всё ниже проверяется на живой машине.

- [ ] Установщик: запрос UAC, служба `FreeTurnDaemon` запущена (`sc query FreeTurnDaemon`), ярлык в «Пуске».
- [ ] Приложение запускается, тема следует системной, значок в трее.
- [ ] Импорт: клик по ссылке `freeturn://` в браузере, вставка из буфера, QR из файла, QR со снимка (Win+Shift+S).
- [ ] Relay: подключение, потоки, скорость и трафик, пинг. Direct: без ссылки на звонок.
- [ ] Трафик идёт через VPN, сокеты ядра мимо туннеля (нет переподключений по кругу).
- [ ] Правило по программе (.exe и папка), по домену; режим «только выбранное через VPN».
- [ ] Ручная капча в окне поверх остальных, закрывается сама; режим «в браузере»; автоматическая в фоне.
- [ ] Смена Wi-Fi и сон: подключение восстанавливается само.
- [ ] Завершить FreeTurnX.exe в диспетчере задач: интернет не пропадает, адаптер FreeTurn отключается.
- [ ] Приватный режим: в логах и на экране нет IP, ключей и ссылки на звонок.
- [ ] Смена иконки: окно, панель задач и трей.
- [ ] «О проекте»: логотип, версия, ссылка на Telegram открывается.
- [ ] Разовое предложение подписаться на Telegram после первого подключения — один раз.
- [ ] Удаление через «Параметры → Приложения»: служба и файлы удалены, данные пользователя остаются.
- [ ] Установщик arm64 на ARM-компьютере.
