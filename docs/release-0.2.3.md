# FreeTurnX 0.2.3

- Windows: локальный мост WireGuard использует connected UDP вместо StdNetBind. Исправление обходит путь отправки WSASendMsg, на котором возникала ошибка invalid pointer.
- Статус VPN становится зелёным только после сообщения движка о проверенном ответе WireGuard-handshake. При отсутствии ответа за 30 секунд или явной ошибке отправки туннель снимается.
- SOCKS5 запускается отдельной кнопкой в настройках. Главная показывает его состояние и отключает соединение; следующее нажатие запускает обычный VPN.
- Главная в компактном режиме помещается по высоте без прокрутки; исправлено пересоздание формы сервера при сохранении поля, сохраняется позиция прокрутки редакторов. Компактный режим больше не помечен экспериментальным.
- Добавлены таймауты ожидания службы и остановки туннеля, окно прогресса загрузки обновления.
- При удалении приложение предлагает удалить службу; ошибка удаления больше не игнорируется.

Проверено: тесты .NET и Go, сборка x64/ARM64, отправка настоящего 148-байтового WireGuard-handshake локальному UDP-приёмнику без изменения маршрутов Windows. Полное соединение с проблемным удалённым сервером и его доступ в интернет в этой среде не подтверждены.

Установщики не имеют доверенной Authenticode-подписи. SignPath Foundation отклонил заявку; предупреждение SmartScreen возможно.
