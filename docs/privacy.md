# Обработка данных

FreeTurnX хранит серверы, ключи, настройки и журналы локально в профиле пользователя. Служба хранит конфигурацию туннеля в `%ProgramData%\FreeTurn\daemon`. При удалении приложения пользовательские настройки сохраняются.

Для подключения программа связывается с настроенным VPN-сервером и, при выборе релея, со службой звонков/TURN. Для проверки CAPTCHA используются сервисы соответствующего провайдера; ручная проверка может открываться в WebView2 или браузере. DNS-запросы обрабатываются согласно настройкам подключения и маршрутизации.

При включённой проверке обновлений приложение обращается к GitHub Releases. Установщик может загрузить и установить Microsoft Edge WebView2 Runtime, если его нет. При переходе по внешним ссылкам открываются соответствующие сайты.

К этим соединениям применяются политики используемых сервисов: [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), [Microsoft](https://privacy.microsoft.com/privacystatement), а также выбранного VPN/relay-провайдера. Они видят данные, необходимые для обработки сетевых запросов. Использование VPN не делает обращения к этим сервисам анонимными автоматически.

В клиенте нет отдельной системы продуктовой аналитики или автоматической отправки журналов разработчику. При самостоятельной отправке журналов проверяйте их содержимое и удаляйте секреты.
