# FreeTurnX 0.2.2

- Экспериментальный клиент SOCKS5 для подключения к раздаче Android: IP, порт, необязательная авторизация и UDP. Управление и статус — на главной кнопке и в трее. SOCKS5 и обычный VPN нельзя включить одновременно.
- Перед запуском туннеля проверяются доступность и авторизация прокси. DNS передаётся через прокси по TCP; адрес телефона исключён из туннеля, чтобы избежать петли маршрутизации.
- Небольшое уменьшение кнопки запуска только при нажатии, едва заметное свечение без пульсации при наведении.
- Выбранные серверы и маршруты выделены системным акцентным цветом Windows с округлённой подложкой.
- Все поля активного сервера явно отключены для редактирования с самого начала подключения.

Проверки: модульные тесты .NET и Go, проверка конфигурации движком, локальное подключение настоящего движка к SOCKS5-серверу с авторизацией и получение HTTP-ответа. Подключение к физическому Android-телефону и системный TUN в этой сессии не проверялись, чтобы не нарушать работающий Hiddify.

Установщики для x64 и ARM64. Доверенной Authenticode-подписи нет: SignPath Foundation отклонил заявку из-за недостаточной публичной известности проекта. SmartScreen может показывать предупреждение.
