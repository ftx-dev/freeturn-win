# Code signing policy

Статус: SignPath Foundation отклонил заявку из-за недостаточной публичной известности проекта и независимых сигналов доверия. Сертификат не выдан; установщики не имеют доверенной подписи. Фонд допускает повторную заявку после роста сообщества и узнаваемости проекта.

Запрашиваемая программа: [Free code signing provided by SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org). Эта строка обозначает выбранную программу, а не уже полученное одобрение.

Автор, ревьюер и ответственный за одобрение подписей: [huhhuh78787878-collab](https://github.com/huhhuh78787878-collab).
Доступ к GitHub и SignPath должен быть защищён многофакторной аутентификацией; запросы подписи релизов требуют ручного одобрения.

Подписывать предполагается только артефакты, происхождение которых подтверждено сборкой исходников этого репозитория. Workflow: [Windows build](../.github/workflows/windows-build.yml).
Состав подписи сторонних компонентов (Amnezia Box, free-turn-proxy, WebView2 bootstrapper) должен быть согласован с фондом. Не выдаём эти компоненты за собственную разработку и не переподписываем их сертификатом фонда без разрешённого правила.

Политика обработки данных: [privacy.md](privacy.md).

Подпись подтверждает происхождение и целостность артефакта, но не гарантирует отсутствие предупреждений SmartScreen.
