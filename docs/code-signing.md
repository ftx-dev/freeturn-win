# Code signing policy

Установщики пока не имеют доверенной цифровой подписи Authenticode.

Подписывать предполагается только артефакты, происхождение которых подтверждено сборкой исходников этого репозитория. Workflow: [Windows build](../.github/workflows/windows-build.yml).

Доступ к инфраструктуре сборки и подписи должен быть защищён многофакторной аутентификацией. Подписи сторонних компонентов сохраняются; их авторство не присваивается проекту.

Политика обработки данных: [privacy.md](privacy.md).

Подпись подтверждает происхождение и целостность артефакта, но не гарантирует отсутствие предупреждений SmartScreen.
