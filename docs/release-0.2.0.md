# FreeTurnX 0.2.0

- Исправлена привязка локального WireGuard / AmneziaWG сокета к loopback: обмен с ядром больше не привязывается к физическому сетевому интерфейсу.
- Обновлены навигация, главная страница и кнопка подключения; исправлены выравнивание векторных иконок и панель действий в логах.
- Добавлены плавные переходы и галочка «Отключить анимации» в настройках.
- Список профилей маршрутизации можно расширять; метка общего профиля отделена от названия. Кнопка переподключения блокируется на время операции.
- Исправлено создание иконки трея; выбор иконки обновляет пользовательский ярлык в меню «Пуск».
- Установщик предлагает удалить предыдущую программу и установить новую с сохранением пользовательских настроек либо выйти. Исправлена кодировка русского текста установщика.
- В README добавлены скриншоты приложения с демонстрационными данными.

Проверка: 91 тест логики прошёл; интерфейс проверен на Windows x64. Обе архитектуры собраны. Полный сетевой тест direct/relay и запуск ARM64 на устройстве ещё не подтверждены.

Установщики и собственные EXE пока без доверенной подписи Authenticode: сертификат издателя недоступен. Предупреждение SmartScreen возможно.

Для упаковки на Windows после сборки Go-бинарников в `build/x64` и `build/arm64` используется `scripts/Package-Windows.ps1`. Нужны .NET SDK 10, NSIS 3 и `build/MicrosoftEdgeWebview2Setup.exe`. Скрипт заново публикует WPF-клиент, проверяет его версию и явно задаёт UTF-8 для NSIS.
