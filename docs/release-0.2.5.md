# FreeTurnX 0.2.5

- «Общий» профиль переименован в профиль «По умолчанию». Сохранённый выбор не меняется.
- Режим маршрутизации и действия профиля располагаются в одной строке при достаточной ширине окна и переносятся на узких экранах.
- Новые правила добавляются в начало списка с наивысшим приоритетом. При переключении правил и изменении порядка сохраняется прокрутка.
- При открытии из трея освобождается захват ввода меню; иконки окон кешируются, чтобы не загружать их повторно при показе.
- Исправлен прозрачный фон диалогов закрытия, обновления и других подтверждений.
- Загрузка обновления показывает объём и проценты, поддерживает отмену и завершается ошибкой при остановке передачи вместо бесконечного ожидания.
- Обновление ожидает завершения клиента после отключения VPN, устанавливает новую версию и запускает установленный экземпляр после успешной установки.

Установщики для x64 и ARM64; контрольные суммы — в SHA256SUMS.txt. Доверенная Authenticode-подпись не настроена.
